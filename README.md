## 🚀 Features

### 🎯 Tic Tac Toe
- **Player vs AI**: Challenge a smart AI opponent with strategic gameplay
- **Player vs Player**: Local multiplayer for two players on the same device
- **Smart AI**: Uses minimax algorithm for optimal moves
- **Score Tracking**: Persistent score tracking until page refresh
- **Modern UI**: Beautiful red and blue theme with smooth animations
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile

### 🎨 Design Features
- Modern gradient backgrounds and glassmorphism effects
- Smooth animations and hover effects
- Responsive grid layouts
- Beautiful typography with Inter font
- Intuitive user interface
- Mobile-first design approach

## 🎮 How to Play

### Tic Tac Toe
1. **Choose Game Mode**: Select between "vs AI" or "vs Player"
2. **Make Your Move**: Click on any empty cell to place your mark
3. **Win Condition**: Get three of your marks in a row (horizontally, vertically, or diagonally)
4. **Scoring**: Wins are tracked automatically for each player
5. **Restart**: Use the restart button to play again or reset scores

### Game Modes
- **vs AI**: Play against a computer opponent that uses strategic thinking
- **vs Player**: Take turns with a friend on the same device

## 🛠️ Installation & Setup

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software or dependencies required!

### Quick Start
1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd mini-games
   ```

2. **Open the game**:
   - Simply open `index.html` in your web browser
   - Or use a local server for the best experience:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (if you have it installed)
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

3. **Start playing**:
   - Navigate to `http://localhost:8000` (if using a server)
   - Or double-click `index.html` to open directly

## 🎯 Game Rules

### Tic Tac Toe
- **Objective**: Be the first player to get three of your marks in a row
- **Grid**: 3x3 playing field
- **Players**: X (Red) and O (Blue)
- **Turns**: Players alternate turns
- **Winning**: Three marks in a row (horizontal, vertical, or diagonal)
- **Draw**: When all cells are filled with no winner
